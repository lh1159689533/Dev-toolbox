# 开发工具集 (dev-toolbox)

个人本地开发工具集合，以 **Chrome 浏览器插件（Manifest V3）** 形式提供。点击工具栏图标弹出快捷面板，可从面板打开工具集，或使用「录制回放」录制/回放浏览器操作。

## 已内置工具

| 工具 | 说明 | 类型 |
| --- | --- | --- |
| TAPD 评论回填 | 拉取工蜂 commit → 解析 `--bug=xxx` / `--story=xxx`（TAPD 缺陷/需求 ID）→ 一键回填评论（含自测截图） | 内置 |
| JSON 格式化 | JSON 字符串格式化为对象，方便查看 | 内置 |
| 时间戳转换 | 时间戳与日期时间互转 | 内置 |
| 文本差异对比 | 对比左右两个文本内容，标记差异 | 内置 |
| JSON 重复 Key 检测 | 识别 JSON 最外层对象中重复的 key，支持删除去重 | 内置 |
| 录制回放 | 录制浏览器操作并一键回放，自动完成重复的自测流程（填表单、提交等） | 内置 |

> 工具通过 `src/data/tools.json` 统一管理，新增工具只需在该文件中登记元信息，即可自动出现在首页并支持搜索与分类。

## 技术栈

Vite + React + TypeScript + CRXJS（`@crxjs/vite-plugin`），打包为 Manifest V3 浏览器插件。路由基于 React Router（HashRouter）。

## 快速开始

```bash
npm install
npm run build
```

1. 打开 Chrome，访问 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择项目 `dist` 目录
4. 点击工具栏中的「开发工具集」图标弹出快捷面板，可在面板中「打开工具集」或使用「录制回放」

## 配置（仅「TAPD 评论回填」工具需要）

工蜂 / TAPD 的认证凭证由插件内置设置页配置：

1. 点击任意工具页面右下角的「设置」按钮（或右键图标 →「选项」）打开设置面板
2. 填入凭证：

| 字段 | 说明 | 获取方式 |
| --- | --- | --- |
| 工蜂 Private Token | `git.woa.com` → 右上角头像 → Settings → Access Tokens，勾选 `read_repository` | 个人设置 |
| TAPD Access Token | TAPD 开放平台 → 个人中心 → 「个人访问令牌」 | 个人中心 |

> 凭证仅保存在本机浏览器 `chrome.storage.local`，由插件后台脚本在请求时注入认证头，不会暴露到页面，也不会上传。

设置页还可配置「默认查询条件」（仓库路径、分支、作者、TAPD 项目 ID），作为工具首次打开时的默认值。

## TAPD 评论回填使用说明

- **工蜂仓库路径**：填 `group/repo` 形式，如 `wedata/wedata3-monorepo`
- **TAPD 项目 ID**：即 TAPD 的 `workspace_id`（数字），在 TAPD 项目 URL 或设置中可见
- commit message 需包含 `--bug=<数字>` 或 `--story=<数字>` 才会解析出 TAPD ID 并启用「编辑」按钮
- 评论模板中「代码 commit」会自动填入 commit 短 ID

## 录制回放使用说明

用于前端自测时，将浏览器上的重复操作（填表单、点提交等）录制下来，之后一键回放。

- **开始录制**：点击扩展图标 → 快捷面板「开始录制」→ 当前页面唤起悬浮条进入录制态 → 正常操作页面（点击 / 输入 / 下拉 / 勾选 / 点击链接跳转）→ 悬浮条「停止」自动保存脚本
- **回放**：点击扩展图标 → 快捷面板下拉选择脚本 → 「回放」；支持点击链接跳转后自动续播
- **管理脚本**：快捷面板「脚本管理」打开工具页，可重命名 / 删除 / 导出 / 导入 / 编辑步骤（删除、排序、修改输入值、插入等待）
- **说明**：录制与回放作用于页面 DOM 事件；对 React 受控表单通过原生 value setter 正确触发输入
